# RAG Pipeline Review

Review and optimize the RAG (Retrieval-Augmented Generation) pipeline including ingestion, chunking, embedding, retrieval, reranking, context construction, and generation.

## Instructions

1. Map the current RAG pipeline components
2. Review chunking strategy and quality
3. Evaluate retrieval quality (recall, precision, MRR)
4. Check embedding model selection
5. Review reranking cost vs quality
6. Verify citation/grounding enforcement
7. Identify failure modes in the pipeline
8. Recommend optimizations with cost/latency impact
