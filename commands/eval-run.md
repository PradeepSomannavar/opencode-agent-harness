# LLM/Agent Evaluation Run

Run evaluation for LLM features or agent systems against an evaluation dataset.

## Instructions

1. Determine evaluation type (LLM evaluation, agent evaluation, prompt regression)
2. Load or prepare evaluation dataset
3. Run evaluation with proper isolation
4. Measure dimensions: correctness, quality, safety, efficiency
5. Compare against baseline if available
6. Detect regressions
7. Generate evaluation report with scores, regressions, and recommendations
