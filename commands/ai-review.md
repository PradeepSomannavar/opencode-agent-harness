# AI Architecture Review

Review the AI system architecture, including LLM integration, RAG pipeline, agent design, model selection, and failure mode analysis.

## Instructions

1. Identify all AI components in the target
2. Review architecture against the `ai-architecture` skill checklist
3. Check model selection justification
4. Review failure mode analysis
5. Verify observability hooks are in place
6. Estimate cost and latency budgets
7. Identify security boundaries
8. Output structured review with findings and recommendations
